# AudioLinkPlayer

粘贴链接 → 直接播放。**息屏、退出 App 之后音频照常继续。**

网页版播放器在你锁屏或切走浏览器时会被系统掐掉音频，这个 App 用的是 Android 的
媒体前台服务（`MediaSessionService`），系统会把它当成音乐播放器对待，所以后台不会断。

## 功能

| | |
|---|---|
| **不下载** | 解析出直链后由播放器边下边播，媒体本身不落到你的存储里 |
| **仅音频模式**（默认） | 优先只拉音频流；站点没有纯音频流时退而取码率最低的那路，流量约为看视频的十分之一 |
| **后台播放** | 前台服务 + `WAKE_MODE_NETWORK`，息屏保持 CPU/网络唤醒；通知栏和锁屏有控制条 |
| **多条链接** | 任意一行右边的 **＋** 继续加；也可以一次粘贴多行；播放列表链接会整个展开 |
| **倍速** | 0.5x – 3.0x |
| **循环** | 不循环 / 列表循环 / 单个循环，外加随机播放 |
| **清晰度** | 视频模式下可设上限（360p–最高），播放中也能手动切某一路 |
| **缓存可控** | 默认 256 MB 上限的 LRU 缓存，放在系统缓存目录，可调可清、可设为 0 关闭 |
| **通用** | 解析内核是 yt-dlp，支持一千多个站点，不限于某一家 |
| **需要登录的站** | 设置里有内置浏览器，你自己登录一次，之后解析会带上该站的会话 |

## 安装

去 [Releases](../../releases) 下最新的一个：

- `AudioLinkPlayer-arm64-v8a-debug.apk` — 2018 年以后的手机基本都是这个
- `AudioLinkPlayer-armeabi-v7a-debug.apk` — 老机器
- `AudioLinkPlayer-universal-debug.apk` — 不确定就装这个（体积大一倍）

首次启动会解压内置的 Python 运行时并联网更新一次 yt-dlp，大概十几秒，之后就快了。

## 用不了的时候

站点改版是常态，yt-dlp 上游通常几天内就跟进。**设置 → 解析引擎 → 立即更新**，
这会直接从 GitHub 拉最新的 yt-dlp，不用等我重新发版。

如果提示需要登录，用 **设置 → 打开浏览器登录** 登录该网站再回来解析。

## 自己构建

推到 `main` 就会触发 GitHub Actions 打包并发 Release，本地不需要装 Android SDK。
本地构建的话：

```bash
gradle :app:assembleDebug
```

## 说明

App 本身不托管、不提供任何内容，只是把你自己有权访问的页面里的媒体地址交给播放器。
不要用它去绕过付费墙或 DRM——yt-dlp 不做这件事，这个 App 也不做。
